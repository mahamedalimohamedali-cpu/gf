# Guess Number

Guess Number is a classic interactive Windows desktop application that challenges users to identify a randomly generated integer between 1 and 100. The project demonstrates core event-driven programming concepts and basic state management within a graphical interface.

## Key Features

- **Automated Game Logic:** Generates a unique target number for every session and validates user input against the generated value.
- **Dynamic Feedback System:** Provides real-time directional hints ("Up" or "Low") to guide the user toward the correct number.
- **Performance Tracking:** Includes an integrated counter that tracks and displays the total number of attempts taken to reach the correct answer.

## Technical Stack

- **Language:** C#
- **Framework:** .NET Framework 3.5
- **UI Architecture:** Windows Forms (WinForms)
